# Excel Employee Data Cleaning Project.

## Project Overview
This is a sample Excel data-cleaning project demonstrating how raw employee data can be organized, cleaned, and reviewed for data-quality issues using Microsoft Excel.

## Workbook Sheets
1. **Employee_Raw_Data** — Original employee dataset.
2. **Employee_Clean_Table** — Cleaned and structured employee data.
3. **Data_Cleaning_Summary** — Summary of data-cleaning activities and quality checks.

## Tools and Techniques Used
- **Excel Formulas:** COUNT, COUNTA, SUBTOTAL, IF, AND, OR, VLOOKUP.
- **Text Functions:** Standardizing text and removing unnecessary spaces.
- **PivotTables:** Summarizing data and reviewing missing values.
- **Conditional Formatting:** Highlighting duplicate values and potential anomalies.
- **Filtering and Sorting:** Organizing records and reviewing unique employee IDs.
- **Excel Tables:** Structuring data for easier filtering and calculations.
- **Data Validation:** Reviewing missing values, duplicates, and unusual numeric values.
- **Formatting:** Standardizing date formats and numeric presentation.

## Project Objectives
- Identify and remove duplicate employee IDs.
- Improve consistency in text and date formatting.
- Review missing information and unusual values.
- Organize the cleaned data into a structured Excel table.
- Document the data-cleaning process.

## Key Results
- Original records: 5,000.
- Records after duplicate removal: 4,975.
- Duplicate employee IDs removed: 25.

## Important Note
This is a sample portfolio project. Potential data anomalies are reviewed and documented rather than changed without verification. The original dataset is retained for comparison.
